每天早上发生的事

  1. 收集计划从多个来源收集近 36 小时的新内容。
  2. 编号每条素材一个编号，去掉发过的。
  3. 编辑按三个问题挑选：会改变判断吗？是新事实吗？有数字或名字吗？
  4. 发布生成网页并保留往期，计划每天更新；任务可能延迟。
