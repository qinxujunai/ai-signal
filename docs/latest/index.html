Parameter Labs 披露 ChatGPT artifacts 漏洞，打开他人分享链接可被接管账号
Parameter Labs 公开了针对 ChatGPT artifacts 实现（Simon Willison 称最新版本叫 HTML previews）的利用方式，该功能把交互式自定义 HTML 应用放在沙盒中展示。The Hacker News 另报道，有研究者因报告「攻击者可在打开其分享链接者的已登录会话中执行代码」的漏洞获得 5000 美元奖金。Hacker News 上相关讨论 302 分、149 条评论。
为什么重要。凡是在 ChatGPT 里点开他人分享链接的人都在风险面上；正在做 HTML 预览、artifact、分享即运行类功能的团队，需要重新测试自己的沙盒边界。
