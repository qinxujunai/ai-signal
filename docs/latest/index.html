头条

Google 发布 Gemini 4 Neon，$3/$15 定价，首发即进 Antigravity
Gemini 4 Neon 定价为每百万 input token $3、每百万 output token $15，模型定位在 Hydrogen 与 Carbon 之间，并在 Gemini app 中取代 Argon。同步上线 API、Antigravity 和 Gemini app，Google 的 Koray Kavukcuoglu 称其主打 coding、知识工作和科研的「快速端到端任务完成」。
为什么重要。这个价位直接决定 coding agent 跑一个任务的成本；而首发就接入 Antigravity，意味着选 Google 的模型等于绑定它的 agent 工具链。
