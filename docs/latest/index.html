Anthropic 三季度营收 170 亿美元，IPO 估值被投资人下调至 1.5–1.6 万亿美元
Anthropic 报告 Q3 营收 170 亿美元，修订版 S-1 中的承诺额达 8950 亿美元。WSJ 称，机构投资人认为其 IPO 估值应在 1.5–1.6 万亿美元，低于此前 2 万亿美元的预期，理由是科技股抛售。TechCrunch 还指出，S-1 写明公司可能“即将”触及 RSI 阈值，且在加速发生后才能确认其存在。
为什么重要。对依赖 Anthropic API 的团队和正在融资的 AI 公司，这是一份同时含收入、承诺额与估值预期的参照系；2 万亿到 1.5 万亿的下修，就是投资人对 AI 收入兑现节奏给出的价格。
