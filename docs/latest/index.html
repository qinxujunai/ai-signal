头条

OpenAI 公开模型 perplexity，并主张按这类指标设定发展节奏限制
OpenAI 公开其模型的 perplexity，即预测数据的能力，并由 Jakub Pachocki 主张依据这类度量设定节奏上限，理由是 2027 年前后可能出现 AI 能力增益的「雪崩」。官方博客同期解释 perplexity 如何衡量模型进展。
为什么重要。如果 perplexity 成为公共口径，模型选型会多一个可复现的比较基准；把它同时用于「限速」讨论，则会影响开发者对发布节奏的预期。
