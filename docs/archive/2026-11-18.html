头条

OpenAI 发布 GPT-6.2 Astra 与 Sol，API 名为 gpt-6.2-astra / gpt-6.2-sol
OpenAI 推出前沿模型 GPT-6.2 Astra 和面向日常工作的 GPT-6.2 Sol，覆盖 ChatGPT Work、Codex 与 API，官方称在专业输出、编码、computer use 与效率上提升且成本更低。Simon Willison 同步发布支持新模型的 LLM 0.38。
为什么重要。Artificial Analysis 主指数上 Astra 仅落后 Claude Fable 5.2，编码一项与 GPT-6 Astra 持平，Epoch AI 则给出 Astra 与 Fable 5.2 并列——换代的边际收益变小，选型要按具体任务评测而不是看版本号。
