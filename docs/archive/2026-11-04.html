Revolut 把默认编码工具换成自托管 GLM，推理成本降约 90%
据 The Register 报道，Revolut 在不到一年内将 AI 编码推理成本削减约 90%，做法是把自托管 GLM 模型设为默认，取代 Claude Code 等商用工具。
为什么重要。按 token 付费的工程团队第一次拿到「自托管开源权重 vs 商用 coding agent」的明确对照数字，商用工具的定价将直接面对这条成本曲线。
