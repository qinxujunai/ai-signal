Anthropic 将 Agent Skills 捐给 Agentic AI 基金会，与 MCP 并列
Claude Code 负责人 Boris Cherny 表示，Agent Skills 最初是 Claude Code 里的实验，因行业广泛采用，Anthropic 决定将其捐给 Agentic AI 基金会，与 MCP 放在一起。
为什么重要。Skills 从一家公司的内部约定变成中立标准，做 Agent 工具链和技能市场的团队不必再绑定 Anthropic 单一实现。
